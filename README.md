This repository preserves the existing Season 9 uNmINeD map export, including
its three dimensions, map tiles, player imagery, marker pages, and historical
viewer backups. It was migrated from CoastalCraft/coastalcraft.github.io.

GitHub Pages publishes main from / (root). Keep .nojekyll and the relative map
asset paths when updating. Existing marker pages retain the Season 9 spreadsheet.
The main website remains https://coastalcraft.github.io/.

The final Season 9 world download remains in Google Drive; it has not been
uploaded or rendered as part of this repository migration. The existing map
export is preserved as-is.
